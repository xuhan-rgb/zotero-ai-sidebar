「WEB 模式不发图」怎么告诉用户

前提：WEB 模式发给网页的是文字材料（LaTeX 源码或 MinerU 解析出的 Markdown），图只带标题文字、不带图像本身。 提示要同时满足三点——只在文字材料真的就绪时出现（否则解析未完成、发的是 PDF，网站自己能读图，提示会说错）、 在按下发送之前看得见、并且能告诉用户怎么办。

解析控件 onState / onAvailability→ 状态桥（按 itemID 记「文字材料就绪」）→ 卡片常驻说明+ 输入行 chip（点击打开须知）+ WEB 使用须知
青色描边＝该方案新增或改变的位置 底栏的 DeepSeek 已就绪 是真实状态，四个方案都按真实占用绘制

二、新增：WEB 使用须知讲清差异 + 讲清怎么发图

WEB 模式使用须知

和 API 模式的区别 · 想让网页模型看图时怎么办（入口：输入行 chip，或 设置 → Zotero AI Sidebar → WEB 模式）

项目API 模式WEB 模式
发送目标Zotero 中配置的模型预设ChatGPT / DeepSeek / ChatGLM / Z.ai / Kimi 或自定义网页
认证方式Zotero prefs 中的 API Key独立 Chrome 中登录网站；Z.ai 支持游客文字聊天
工具能力可使用 Zotero / 模型工具循环同步网页回答，不运行 API 工具循环
论文上下文用「原文」控制 API prompt 上下文由 WEB 文件上传流程自动附加（LaTeX 或 MinerU Markdown）
联网控制「联网」使用 API Web Search「联网」禁用；用网页自身的搜索开关
图片 / 图表可直接附图；PDF 图会随选区上下文给出不发送论文里的图：只带图注文字，模型看不到图和版式
附件 / 下载附件走本地文件；生成文件直接存回 Zotero只上传 LaTeX / Markdown / PDF；网页给出真实附件或下载 URL 才能存回
想让网页模型看图？今天有两条路：① 把专用浏览器窗口显示出来，在网页里自己拖入图片或 PDF；② 解析还没完成时，插件会自动发 PDF，网站自己能看到图（不可控，只在解析前那一刻）。
注意（正在修）：WEB 模式下用输入框的「截图 / 图片」按钮附加的图片现在会被静默丢弃——不改代码就直接写"怎么发图"，用户会更困惑。
即将支持：输入框 @ 选择当前论文已解析的图 / 表，或直接插入截图；做好后 chip 变成 @ 附图。
