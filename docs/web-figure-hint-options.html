「WEB 模式不发图」提示放在哪里

前提：WEB 模式发给网页的是文字材料（LaTeX 源码或 MinerU 解析出的 Markdown）， 图只带标题文字、不带图像本身。所以提示必须同时满足两点—— 只在文字材料真的就绪时出现（否则解析未完成、发的是 PDF，网站自己能读图，提示会撒谎）， 以及 在用户按下发送之前看得见。

解析控件 onState / onAvailability→ 状态桥（按 itemID 记「文字材料就绪」）→ 论文卡片常驻说明+ composer 短提示

细节：短提示的文案和悬停说明

  • 输入行 chip 候选（必须短）：WEB 不含图 · 仅文字 · 文字版 · 无图
  • 卡片长句（现有）：WEB 模式只发送论文文字，图不会发送
  • 两种位置的悬停说明共用同一段文字，见下方预览
  • 将来 @ 选图做好后，chip 改成可点击：@ 附图，点击直接打开图/表选择面板
网页模型看不到论文里的图和版式；需要看图时，请在问题里描述图表内容，或在网页中手动附加图片或原始 PDF。
  • 不做的事：无条件显示（解析未完成时会误报）；靠问题里出现「图 / figure」才提示（漏判时用户不知道为什么答错）；卡片和输入行都写长句（重复且吵）。
  • 技术前提：composeInputStatus() 是同步函数，拿不到 MinerU 的异步解析状态，所以方案 A/B/C 都需要上面那条状态桥。
