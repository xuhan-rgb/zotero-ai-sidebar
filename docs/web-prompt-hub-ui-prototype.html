按钮最少化

Zotero 主界面只新增一个渠道选择“Web Hub · 模型”和一个 ↗ 发送按钮；任务状态放在消息流中，不增加常驻大面板。

两次人工动作

用户在网页端负责“发送”和“复制回答”。Hub 自动处理上下文、打开入口、任务关联、格式预览和写回 Zotero。

本地能力保留

回答导入后，写笔记、分支和基于既有 PDF 选区的批注草稿仍由 Zotero 本地完成，不要求网页访问本地数据。
