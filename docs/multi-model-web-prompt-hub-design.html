网页辅助模式

Zotero 自动把任务送到 Hub；用户选择网页模型、粘贴发送，再把回答复制回 Hub。

  • 不需要浏览器扩展
  • 不抓取第三方网页
  • 可以使用网页订阅
  • 保留 Zotero 本地写笔记能力
可选

API 自动模式

选择已配置 API 的模型后，Hub 或 Zotero 自动发送、流式显示并回传，适合需要完全自动化的任务。

  • 官方自动化接口
  • 支持工具调用
  • 支持并发和取消
  • 按 API token 计费
混合

按任务选择

普通长问答使用网页端；需要 Zotero 工具、高亮定位或完全自动流程时切换 API。

  • 同一任务统一归档
  • 网页/API 共用 Prompt
  • 关键任务保留工具能力
  • 控制总体费用

第一版范围

把 Hub 做成可靠的任务中转站，不把它伪装成能够控制所有网页模型的通用 Agent。

任务传送Zotero 通过 localhost 将 Prompt、来源对话、选区摘要和任务 ID 发给 Hub。
网页入口每个厂商配置名称、首页/对话 URL 和打开方式；按钮执行“复制 Prompt + 打开网页”。
回答导入用户在厂商网页点击复制，再在 Hub 点击“从剪贴板导入”，由任务 ID 回写 Zotero。
对话链接用户可把厂商对话 URL 保存到当前 Zotero 对话，下一轮继续打开同一页面。
本地写入回答回到 Zotero 后继续支持写笔记；高亮仅针对发送前保存的当前 PDF 选区。
安全边界Hub 只监听 127.0.0.1，使用随机访问令牌，不记录完整 PDF，不读取浏览器 Cookie。
