3通过 WEB 使用网页模型

WEB 模式通过本机 Web Agent 控制一个独立 Chrome 配置，把网页回答持续同步回 Zotero。它适合使用网页账号；API 模式不依赖 Chrome，也不会受到 Web Agent 状态影响。

本节的 Z.ai、自动端口分配和登录检测流程适用于 v0.8.7。从旧版升级时，请安装新版 XPI，并按账号窗口提示安装或更新其配套 Web Agent ZIP。

4用 API 对正在读的论文随便问

在输入框直接用自然语言问就行——比如「公式1和 figure1 是什么意思」「这篇的核心贡献是什么」「和 X 方法比有什么区别」（这些只是例子，问什么都可以）。模型会自己决定要不要读当前条目、PDF 文本、注释、选区或截图，过程在「思考与上下文」里显式展示。

整篇提问

“帮我总结”“核心贡献是什么”“和 X 比较”。不选任何东西时，默认带整篇论文上下文（📄 原文 打开时）。

聚焦某段

在 PDF 里选中一段，输入框上方出现选中片段 chip，提问时选区会叠加在全文之上；想只看选区就关掉「📄 原文」。

截图 / 贴图

底栏「截图 / 图片」把画面作为图片附件发给多模态模型——既显示在对话里，也真正发给模型。

公式 / 图表也能直接问

带 LaTeX 源 的论文，问「公式1是什么意思」「figure1 在讲什么」会从 LaTeX 源精确命中（含图像），而不是 PDF 文本层乱码——同样是自然语言，不用记任何指令。

让 AI 高亮 / 加注释

给 PDF 加高亮 / 批注是 Agent 已内置的写入工具，直接用自然语言喊就行：「把这段的重点句子高亮」「给这段加条注释说明它在讲什么」。模型会自己选中对应段落、按颜色分类上高亮或加文本批注，trace 里能看到它选了哪段、上了什么色。颜色分类在设置的「PDF 注释颜色预设」里统一定义。

✍️ 这类「写回 PDF」都是 Agent 显式工具调用、过程可见、且受权限控制——默认模式会先确认，开 YOLO 可直接执行，不会偷偷改你的 PDF。

8四步上手

先选 API 或 WEB

在输入区底栏切换。API 使用模型预设和 Zotero 本地工具；WEB 使用 ChatGPT / DeepSeek 等网页账号。

完成对应配置

API 点顶部「设置」新增模型预设；WEB 选择网页服务后点「账号」，补齐依赖、安装配套 Web Agent，再完成网站登录。Z.ai 游客可文字聊天，上传附件需登录。

确定对话与上下文

用数字标签切换对话，用“无 / 1轮 / 全部”决定发送多少历史；API 模式还可开关“联网 / 原文”。

提问并查看任务

直接输入问题，或点「总结论文 / 全文重点 / 解释选区」。生成中的任务可在“队列”查看；精读时点顶部「沉浸」，结果可继续写入笔记或 PDF 标注。

💡 数据本地优先：不开同步时什么都不出本机；开了 WebDAV 才会把含预设（含 API key）、对话、批注、翻译缓存的 state.json 推到你自己的端点，不发给 zotero.org 或第三方。
